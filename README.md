# Интернет-магазин на PHP

Учебный проект интернет-магазина: каталог, корзина, админ-панель.

## Стек
- PHP 8.5 (без фреймворков)
- MySQL
- Bootstrap 5
- PDO, сессии

## Возможности
- Каталог с фильтрацией, поиском, сортировкой, пагинацией
- Страница отдельного товара + похожие товары
- Корзина по id (данные тянутся из БД)
- Админ-панель: CRUD товаров, загрузка изображений
- Авторизация с хешированием пароля (password_hash)
- CSRF-защита форм

## Установка
1. Клонировать репозиторий.
2. Создать БД `shop`, импортировать `sql/dump.sql`.
3. Скопировать `config.example.php` в `config.php` и указать данные подключения.
4. Запустить: `php -S localhost:8000`
5. Открыть http://localhost:8000

## Демо-доступ в админку
- Логин: `admin`
- Пароль: `admin123` (сменить после первого входа!)
